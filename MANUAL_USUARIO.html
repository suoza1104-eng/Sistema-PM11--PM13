Manual do Usuário - Sistema de Controle PM13

Guia completo para operação local de planos e balanceamento de carga de paradas

1. Visão Geral

O Sistema PM13 é uma ferramenta local corporativa desenvolvida para substituir planilhas complexas de controle de paradas programadas de manutenção PM13 na indústria siderúrgica. Ele permite cadastrar planos, vincular itens de manutenção, importar dados diretamente de planilhas unificadas e balancear a carga de trabalho de HH (Homem-Hora) e efetivo necessário ao longo de um horizonte móvel de paradas futuras.

Características Principais:
  • Funcionamento 100% Offline: Não depende de internet, servidores de nuvem externos ou CDNs.
  • Banco de Dados Robusto: Alimentado por um banco SQLite local, garantindo consistência transacional.
  • Importação Inteligente: Lê planilhas XLSX unificadas de forma nativa e detecta inconsistências de preenchimento.
  • Visualização de Carga: Gráficos SVG interativos de HH, efetivo ou ordens, com mapa de calor e painel de detalhamento lateral por parada.

2. Como Iniciar o Sistema

O sistema é executado localmente. Para iniciá-lo, siga os passos abaixo:

  1. Navegue até a pasta de instalação do sistema.
  2. Dê dois cliques no arquivo INICIAR_PM13.bat.
  3. O script detectará o interpretador Python, iniciará o servidor HTTP local e abrirá automaticamente o navegador no endereço http://127.0.0.1:8765.
  4. Mantenha a janela preta do prompt de comando aberta enquanto estiver utilizando o sistema. Para encerrar, feche a janela ou clique no botão Encerrar Sistema no canto inferior esquerdo da barra lateral da tela.

3. Lógica e Regras de Negócio Importantes

O sistema calcula os indicadores e o calendário de paradas futuras de forma automatizada com base nas seguintes fórmulas matemáticas:

3.1. Calendário de Ocorrência de Planos

Um plano de manutenção programada ocorrerá em uma determinada parada \(S\) (onde \(S\) representa o contador numérico da parada) se, e somente se, satisfizer as seguintes condições:

S ≥ R     e     (S - R) mod C == 0

Onde:

  • R: Contador de Referência (primeira parada cadastrada onde o plano ocorreu).
  • C: Ciclo do Plano (frequência de ocorrência dada em número de paradas, ex: 3, 6, 12).

3.2. Aproveitamento de Parada e Efetivo Médio

Para planejar a quantidade de pessoas necessárias (Efetivo) em cada parada, o sistema calcula a duração produtiva total de cada parada somando as horas de todos os turnos configurados no projeto e multiplicando pelo Fator de Aproveitamento:

H_produtivas = (Σ Horas dos Turnos Ativos) × Fator_Aproveitamento

A quantidade de efetivo necessário (número de pessoas da equipe) para a parada é calculada dividindo o total de HH acumulado da parada pelas horas produtivas, arredondando para cima (teto matemático):

Efetivo = ⌈ HH_total / H_produtivas ⌉

3.3. Restrição de Caracteres

Limite Crítico de Descrições (35 Caracteres):
O ERP SAP corporativo limita a descrição da ordem de manutenção a 35 caracteres.
  • Planos ou itens com descrições que ultrapassarem 35 caracteres serão marcados com um alerta amarelo de advertência nas tabelas e no painel gerencial.
  • Ao cadastrar ou editar planos/itens no sistema, o contador de caracteres exibirá em tempo real se a descrição exceder esse limite.

3.4. Erros de Cópia e Cola (Divergências de Subárea)

O sistema analisa se há divergência entre a sigla do sistema no código do plano (STP, STE, STF, STD) e a descrição escrita. Caso o código contenha STP (SIST-P) mas a descrição mencione SIST-E, por exemplo, um aviso visual será mostrado apontando a divergência para correção.

4. Telas do Sistema

4.1. Visão Geral (Dashboard)

Apresenta os KPIs gerenciais consolidados do projeto ativo, a distribuição de HH por Centro de Trabalho (equipes) e o número de inconsistências cadastrais pendentes.

  • Alertas Clicáveis: Caso existam planos sem contador de referência, itens sem plano ou descrições acima do limite, um box amarelo exibirá esses erros. Ao clicar sobre qualquer aviso (ex: "12 itens sem plano"), você será redirecionado para a tela correspondente já com os filtros aplicados para rápida correção.

4.2. Catálogo de Planos

Exibe a tabela com todos os planos cadastrados. Você pode pesquisar por código ou descrição, filtrar por ciclo, status e inconsistência cadastral.

  • Exclusão Segura: Se você tentar excluir um plano que possui itens de manutenção vinculados, o sistema abrirá um menu especial perguntando se você deseja desvincular os itens (deixando-os temporariamente sem plano) ou transferir todos os itens vinculados para outro plano do projeto.

4.3. Itens de Manutenção

Gerenciamento das atividades específicas de manutenção. Possui dois recursos essenciais de produtividade:

  • Edição Rápida na Tabela (Inline): Você pode alterar os valores de t(H) (duração) e Efetivo diretamente na tabela sem abrir modais. Basta clicar sobre o valor, digitar o novo e tirar o foco. O Homem-Hora (HH) da linha será recalculado instantaneamente e gravado no banco de dados.
  • Ações em Massa: Selecionando as caixas de verificação (checkboxes) ao lado dos itens, abrirá uma barra flutuante no rodapé para executar ações em lote:
    • Atribuir Plano em Massa: Abre uma tela onde você escolhe o plano de destino e o sistema gera uma prévia de impacto em tempo real mostrando quantos itens serão alterados, o HH que será deslocado e em quais paradas futuras a carga será aplicada.
    • Editar Campos em Massa: Permite alterar GPM, Centro de Trabalho, Condição ou Prioridade de dezenas de itens de uma só vez.
    • Ativar, Inativar ou Excluir em Lote.

4.4. Balanceamento de Carga

Permite balancear o HH, efetivo ou quantidade de ordens projetadas ao longo do horizonte (padrão de 12 paradas futuras).

  • Mapa de Calor (Heatmap): Mostra a intensidade de carga de HH por Centro de Trabalho, GPM ou Plano ao longo das paradas em cores indicativas (Verde = Carga Baixa, Laranja/Vermelho = Picos de Trabalho).
  • Detalhes da Parada (Drill-down): Clicando sobre qualquer coluna do gráfico de paradas, abrirá uma gaveta lateral (Drawer) detalhando todas as ordens planejadas para aquela parada específica, com gráficos de distribuição por GPM e exportação direta da parada para CSV.

4.5. Importador de Planilha Excel

O assistente de importação guia você passo a passo na carga de dados:

  1. Upload: Arraste e solte o arquivo XLSX corporativo na área indicada.
  2. Destino: Selecione se deseja criar um novo projeto/cenário ou importar os dados para um projeto existente (com opção de substituir todos os dados ou mesclar mantendo os itens que já existem).
  3. Efetivo Padrão: Como a planilha Excel original não possui efetivo preenchido, informe o valor padrão (geralmente 1 ou 2) a ser atribuído temporariamente aos itens importados.
  4. Diagnóstico de Inconsistências: O leitor nativo processa o XML interno da planilha e apresenta uma tabela com todos os erros de preenchimento e advertências da planilha antes de salvar no banco.
  5. Gravação: Confirme para consolidar no banco.

5. Backups e Pontos de Restauração

A barra de navegação conta com um item de Backup. O sistema gera backups compactados em arquivos .zip contendo o arquivo pm13.db e metadados JSON com informações de quais projetos e quantidade de itens estão inclusos no snapshot.

Atenção ao Restaurar Backups:
Ao restaurar um arquivo de backup, o banco de dados atual será completamente substituído pelo banco do backup. O sistema cria automaticamente um backup de segurança pré-restauração chamado auto_safety_before_restore na pasta backups/ para o caso de arrependimento.

6. Solução de Problemas (Troubleshooting)

O comando INICIAR_PM13.bat fecha sozinho ou dá erro de Python

O sistema exige Python 3.11 instalado. Verifique se o executável do Python está no PATH do Windows abrindo um prompt de comando e digitando: python --version.

O navegador abriu, mas exibe uma página de erro

Verifique no prompt de comando se o servidor conseguiu iniciar sem erros de porta bloqueada. O sistema tenta usar a porta 8765, mas se estiver ocupada por outro software corporativo, ele subirá na primeira porta livre subsequente (8766, 8767...). Olhe no prompt qual endereço foi impresso (ex: http://127.0.0.1:8766) e acesse manualmente.

O status do banco exibe "Desconectado" no topo da tela

Isso indica que o servidor local Python foi encerrado ou a conexão de rede local com a porta do servidor caiu. Verifique se o prompt de comando preto ainda está aberto ou execute novamente o INICIAR_PM13.bat.
