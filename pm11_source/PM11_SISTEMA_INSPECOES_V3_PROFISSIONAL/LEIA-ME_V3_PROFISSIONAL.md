# PM11 V3 Profissional

Esta versão consolida a reconstrução do PM11 usando o PM13 fornecido como referência direta de UX, CSS, tabelas, barras contextuais, filtros e Balanceamento.

## Instalação limpa

Extraia a pasta e execute `INICIAR_PM11.bat`.

## Atualização sobre uma instalação anterior

Se quiser preservar um banco PM11 já utilizado, faça backup de `data/pm11.db`, copie os arquivos da V3 sobre a pasta anterior e mantenha/restaure seu `data/pm11.db`. As migrações são executadas automaticamente ao iniciar.

## Endereço

`http://127.0.0.1:8766`

## Importante

O sistema é local. A janela preta do servidor mostra logs detalhados e deve permanecer aberta durante o uso.
